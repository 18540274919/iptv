## 播放链路

- 绵阳、泸州、遂宁读取官网实际启用的播放器地址，忽略 HTML 注释中的旧源。绵阳签名从网页实时读取，不写死。
- 内江读取官网 `live_id` / `live_type`，再请求同站 `web/video_ajax.php` 的直播地址。
- 达州、甘孜使用官网播放器的 `cms/home/content?id=…`，核对频道 ID 与电视类型。
- 巴中读取官网 `sctv/tv/index/tv.json`，按 `channelId` 精确选台。
- 阿坝使用官网公开 `nodeClient/node`（汉语租户 `c3200`）与 `getUnifiedConfiguration`。按官网前端 `a0d8` 模块的公开流程生成 `md5(key + pathname + 十进制到期时间)`，有效期 60 秒；配置只在内存中短缓存，不写入文件、日志或订阅，也不发给媒体 CDN。

目录短缓存 30 秒，同一请求合并并发；绵阳、阿坝按官网播放器方式复用正在播放的合法网宿会话，每次读取媒体清单，空闲 10 分钟回收。`wsTime` 限制新建会话，已有 `wsSession` 可继续播放；不因短签到期强换会话，避免 TS 时间戳回退。CDN 明确拒绝会话时重新走官网流程一次，网络抖动不切会话。目录连接错误仅重试一次，目录 HTTP 拒绝和超时不重试。

播放列表仅保存稳定的 `sichuan-cities-*` 引用。遂宁、达州四路的清单与分片要求官网 Referer，默认全代理；其余九路默认中继清单，分片直连。全代理兼容订阅也可用。绵阳、阿坝的官方网宿调度节点按发布域名和本台完整目录校验，拒绝串台、陌生域和私网节点。

## 台标与节目单

13 路均提供官方图，并备份进内置台标包。达州、巴中优先使用频道图；绵阳、内江、甘孜、阿坝使用所属广电的官方标识。泸州暂用大听网官方标识，遂宁使用官网图标，均有明确来源，没有引入外部台标库。

暂不提供 EPG 和回看：绵阳节目单虽然日期标签随当前周轮换，正文仍写 2020 年旧编排；内江只返回整点「精彩节目」占位；达州、甘孜、巴中当天节目单为空；阿坝公开电视目录未给可用当天编排；泸州、遂宁播放器页面没有节目单。央视网候选代号也未取得有效对应节目单，不拼第三方数据。
